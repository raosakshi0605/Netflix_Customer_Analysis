# 🎬 Netflix Customer Analytics

## 📌 Project Overview

Netflix Customer Analytics is an end-to-end Data Analytics project focused on exploring customer information, subscription patterns, revenue, and viewing behaviour.

This is my first major integrated Data Analytics project, bringing together concepts and tools that I had previously explored through smaller projects.

The project covers data cleaning, exploratory data analysis, SQL querying, and interactive dashboard creation using Tableau.

## 🎯 Project Objectives

- Understand customer distribution and subscription patterns.
- Analyze revenue across different subscription plans.
- Explore customer viewing behaviour and content preferences.
- Examine device usage and account status.
- Present meaningful insights through visualizations and dashboards.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning and preprocessing
- **Pandas:** Data manipulation and analysis
- **Matplotlib:** Data visualization
- **Jupyter Notebook:** Python development environment
- **SQL:** Data querying and analysis
- **Tableau:** Dashboard creation and visualization
- **GitHub:** Project version control and documentation

## 📊 Project Workflow

### 1. Data Cleaning & Preprocessing
- Imported the raw Netflix customer dataset.
- Prepared and processed the data using Python.
- Created a cleaned dataset for further analysis.

### 2. Exploratory Data Analysis (EDA)
- Used `head()`, `info()`, and `describe()` to understand the dataset.
- Checked missing values and duplicate records.
- Created graphs to explore data patterns and distributions.

### 3. SQL Analysis
Performed SQL queries to analyze:
- Total and active customers
- Customers by subscription plan
- Revenue by subscription plan
- Popular genres
- Country-wise customer distribution
- Device usage
- Average watch hours
- Movie vs TV content preferences
- Top 10 customers by revenue
- Account status distribution

### 4. Tableau Dashboard
Created visualizations and an interactive dashboard to present customer analytics and viewing insights.
